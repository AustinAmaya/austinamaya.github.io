Calder privacy policy

Last updated: 12 October 2026

What Calder is

Calder is a single-user personal assistant for Austin. It is not offered to the public and has no other users. See the home page.

Data Calder accesses

With Austin's permission, Calder accesses his Google Calendar and Google Tasks data: calendar names, events and their details, and task lists and tasks. It requests only the Google Calendar and Google Tasks permissions it needs.

How the data is used

The data is used only to provide the assistant's features to Austin: showing and summarising his schedule, planning his day, preparing briefs and reviews, and creating or changing calendars, events and tasks when he asks.

Where the data is stored

Calendar and task data is read and written only on Austin's own server. Calder keeps the authorization needed to reach Google on that server, and Austin can revoke it at any time from his Google Account's third-party access page.

Sharing

Austin's Google data is never shared with, disclosed to, or sold to anyone else, and is never used for advertising. Calder's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Data is kept on Austin's server only as long as he wants the assistant to work with it. Austin can delete it, or revoke Calder's access, at any time.

Changes

If this policy changes, the new version will be posted on this page with a new date.
